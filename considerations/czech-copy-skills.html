Czech copy skills

Survey of what already exists for writing Czech copy with agents, and what is worth inheriting into this directory.

2026-08-19 Sources: GitHub API · npm · claude.ai catalog · skill registries Verdict: inherit 1, maybe 2

Headline finding

A “Czech copywriting” skill does not exist. The entire published genre is Czech anti-AI-slop and humanizer skills.

Which means: the Czech ecosystem has built exactly one thing, and it is the Czech counterpart to the unslop skill already in this library. Nobody has published Czech brand voice, Czech SEO, Czech long-form, or Czech product-copy skills. That gap is real and unfilled.

Recommendation

Inherit nowork-ai/anti-ai-slop-cz. It is the only one written as guidance for writing rather than as a tool for repairing text. Organized in four layers — vocabulary, sentence patterns, punctuation, formatting — with LinkedIn-specific rules and a pre-submit self-check. Sized to actually load: 5 KB in context, 6 KB reference pulled on demand.

It is a Czech rework of jalaalrd/anti-ai-slop-writing, not a translation — the banned-phrase list is genuinely Czech („V dnešní době…“, „Stojí za zmínku, že…“, „posunout na další úroveň“), and it names Czech-specific tells like the LinkedIn „A tady je proč ↓“ hook.

If you also want text repair

Pair it with one of bejek/humanizer-czech or mirecekd/humanizer-cz. Both are independent 27-pattern lists that heavily overlap; installing both is redundant and they will fight over the same trigger phrases. bejek has more stars and the style-selection flow; mirecekd has the research citations and MIT clarity.

Overlap with unslop

Direct. unslop covers the same job in English and is marked “must always apply.” Any Czech skill added here needs its description scoped tightly to Czech text, or the two will both fire on every writing task and duplicate instructions in context.

Adjacent Czech tooling

Not copy skills, but useful as verification references when writing Czech.

cesky-narodni-korpus-skill

MIT. Queries the Czech National Corpus API — concordances, frequencies, collocations. The best-engineered Czech skill found: evals, six reference docs, a Python client. Use it to check whether a phrasing is actually idiomatic rather than guessing.

npm: czech-vocative

5. pád for personal names. Relevant for any copy that addresses a reader by name.

npm: czech-inflection

Declension of Czech words. Useful for templated or generated copy.

npm: @cspell/dict-cs-cz

Czech spelling dictionary for cspell. Pipeline-level, not agent-level.

The Czech developer landscape

No notable Czech developer is publishing a general skills library. What exists is a long tail of single-purpose Czech-domain skills, almost all at 0–5 stars, one skill per repo:

  • Fakturoid invoicing API and DigiSign e-signature, both by the same author
  • shopsync-plugins — ERP and e-shop integrations (Pohoda, Money, ABRA, Helios, Shoptet)
  • Bakaláři school system API, countly.cz financial calculators, Czech accident-report PDF filling
  • katerinas-ricky-gervais-tone — the one Czech voice skill found, and it is a comedy-rewrite novelty rather than usable copy guidance

Takeaway: Czech agent-skill authorship is hobbyist and fragmented. There is no maintained hub to subscribe to, so anything inherited here should be vendored — copied in and owned — not tracked as an upstream dependency.

Before inheriting anything

A SKILL.md is instructions your agent will follow

Every repo here is single-author and low-star. Read the full file before it lands in ~/.claude/skills/, and pay particular attention to the two carrying NOASSERTION licenses — anti-ai-slop-cz and thatmike1/humanizer-cz — where reuse terms are unclear and worth confirming before vendoring.

All five are pure Markdown with no executable code. The only exception in this document is the corpus skill, which ships a Python client that makes outbound network calls and handles an API token.

What was searched

Recorded so this does not get re-run from scratch. The claude.ai skill catalog and org plugin catalog both returned zero results for every Czech, copywriting, localization, and tone-of-voice keyword. GitHub repository search was productive; GitHub code search was not, and gh is not installed on this machine, so the REST API was used directly via curl. The skills.rest and awesomeskill.ai registries have no Czech entries. VoltAgent/awesome-agent-skills — 1000+ skills — contains no match for “czech”, “česk”, or “cesk”. The productive queries were transliterated Czech words in repo descriptions: cesky skill claude, czech claude skills, cestina. English-only queries such as czech copywriting and tone of voice skill czech brand returned nothing useful.
